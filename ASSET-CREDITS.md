# Asset and source notes

## User-supplied CuteFela assets
- CuteFela logo (used as header logo and favicon source)
- School crests supplied for the programme network; each is placed on the same white canvas for consistent visual sizing.
- UNFCCC COP28, COP29, COP30 and UNCCD COP16 photographs supplied by the user.
- Polar bear photograph supplied by the user.
- Three supplied MP4 videos, transcoded locally for web autoplay.
- EYC and Wildlife Rehabilitation project proposal excerpts, used selectively as project-documentation visuals.
- Official SDG icon files and SDG wheel supplied in `SDGs.zip`.

## Stock photography loaded from Pexels
Pexels pages used by the site include sea turtle, sea lion, rhinoceros, clownfish, jellyfish, ostrich, seahorse, gorilla, fox, kangaroo and lion imagery. Individual page credits are linked on species detail pages. Pexels license: https://www.pexels.com/license/

## Species reference links
Each species detail page links to an IUCN, NOAA, Virunga, Great Barrier Reef Foundation, iNaturalist or other specialist source. The copy avoids unsupported countdowns and blanket statuses for groups that contain multiple species.
